有限元平衡方程组求解器（2.4 作业）
===================================

1. 环境依赖
------------
- Python 3.6+
- NumPy
- SciPy
- Matplotlib（可选，用于绘图）

安装命令：
pip install numpy scipy matplotlib

2. 程序文件
------------
fem_solver_24.py        - 主程序（包含所有功能）
truss_1d.json           - 一维桁架输入
truss_2d.json           - 二维桁架输入
ill_conditioned.json    - 病态矩阵输入
tridiagonal_n10.json    - 三对角矩阵 n=10
tridiagonal_n100.json   - 三对角矩阵 n=100
generate_tridiagonal.py - 生成三对角矩阵的脚本（可选）

3. 运行方式
------------
直接运行（将执行所有内置算例）：
python fem_solver_24.py

如果只想运行特定算例，可在代码中注释或修改 main_24() 函数。

4. 输出内容
------------
- 每个算例的矩阵、解向量、残差、相对误差、条件数等。
- 对于 Poisson 算例，输出网格信息、装配时间、求解时间、最大误差、L2 相对误差、相对残差。
- 大规模算例输出矩阵非零元个数、自由度。

5. 输入文件格式
----------------
JSON 文件格式请参考提供的示例。注意：
- 所有编号从 1 开始（程序内部自动转换）。
- 矩阵 K 为二维列表，右端项 R 为一维列表。

6. 注意事项
------------
- 病态矩阵测试中，截断后可能无法 LDLT 分解，程序会捕获并提示。
- Poisson 算例自动生成网格，无需额外输入文件。
- 若大规模算例运行时间过长，可减小网格尺寸。

7. 结果验证
------------
所有输出结果与理论值一致（详见报告）。
