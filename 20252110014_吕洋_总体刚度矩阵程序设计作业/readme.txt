运行说明

环境依赖
- Python 3.6 或更高版本
- NumPy 库（安装命令：pip install numpy）

程序文件
- fem_truss.py：主程序
- example_1d.json：算例1 的输入文件（一维两单元杆）
- example_2d.json：算例2 的输入文件（二维两杆桁架）

运行方式

1. 直接运行（演示两个算例）
在终端（或命令提示符）中，进入程序所在目录，执行：
python fem_truss.py
此时程序会自动依次计算并输出算例1和算例2的结果，无需额外输入文件。

2. 指定单个输入文件（JSON 格式）
若只运行某个算例，可将对应的 JSON 文件作为参数传入：
python fem_truss.py example_1d.json
或
python fem_truss.py example_2d.json

输出内容
程序会输出以下信息：
- 对号矩阵 LM（显示每个单元对应的全局自由度编号）
- 总体刚度矩阵 K，并检查对称性、奇异性
- 节点位移（所有自由度）
- 约束反力（固定自由度上的反力）
- 单元计算结果（长度、方向余弦（二维）、应力、轴力）

输入文件格式要求
JSON 文件中的节点编号、自由度编号均从 1 开始（如 IEN: [[1,3], [2,3]]），程序内部自动转换为 0 基索引。
具体格式请参考 example_1d.json 或 example_2d.json。

注意事项
- 请确保 JSON 文件为 UTF-8 编码，且格式正确。
- 若文件路径包含空格，请用引号括起来。

验证结果示例（部分关键值）：
- 算例1 位移：u2=0.1, u3=0.15；反力：自由度1 = -10
- 算例2 位移：u3=38.284271, v3=-10.0；应力：单元1=-10, 单元2=14.142136
所有结果与作业要求一致。
